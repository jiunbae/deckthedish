# 주방덱 · Deck the Dish · キッチンデッキ

카드로 차리는 동네 식당 — 게임 소개, 개인정보 처리방침, 이용약관, 지원, 오픈소스 라이선스 페이지와 웹 플레이 빌드.

- 사이트: https://jiun.dev/deckthedish/
- 페이지 생성: `python3 build.py` (src/*.html 본문 + 공통 머리·꼬리말, 문구는 site.js)
- 이미지: 게임 저장소의 `tools/make_brand.py <이 폴더>` 로 워드마크·히어로·아이콘·OG 생성
- 웹 빌드: 게임 저장소에서 Web 내보내기 후 `build/web/*` 를 `play/` 로 복사

문의와 버그 제보는 이 저장소의 Issues 로 남겨 주세요.
